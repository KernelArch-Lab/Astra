\section{Conclusion}
\label{sec:conclusion}

\sysnamefull mediates every zero-copy IPC message on stock Linux
through an unforgeable 128-bit capability token, and does it cheaply
enough to matter. The slot-indexed validate path costs
\gateOverheadTail\,ns per message at p99 while keeping a $2^{96}$
forgery space; the gated round trip stays within \aeronGapPercent\%
of Aeron's published 250\,ns floor from 64\,B to 16\,KiB payloads;
revocation takes effect within \revokeTail\,$\mu$s of the
\texttt{revoke()} call; and the gate scales through 16-producer MPSC
contention. None of that required a kernel patch, a hypervisor, or
capability hardware.

We see this as one piece of a larger argument: that capability
discipline can become the default for userspace runtimes that broker
untrusted code on commodity machines---including LLM-agent tool
execution (M-22 AgentGuard) and confidential-compute attestation
(M-23 ConfCompute), both in preparation as follow-up papers.

The artefact is open source. One command,
\texttt{scripts/run\_paper1\_sweep.sh}, reproduces every figure on a
fresh Fedora x86-64 machine, no internet access required for the
required baselines.
